# Jennifer Estama — Portfolio

## Publish with GitHub + Vercel
1. Extract this ZIP file on your computer.
2. In your GitHub repository (`jenestama-bitbyts`), upload `index.html` and the entire `assets` folder.
3. Commit the changes to the `main` branch.
4. Vercel should automatically redeploy the site if the repository is already connected.
5. Open your Vercel deployment URL to check the portfolio.

The website is a static HTML/CSS page. No build command or framework is required.

## Before publishing
- Confirm you are comfortable displaying the email address and phone number publicly.
- The client surnames are abbreviated/censored in the portfolio.
- Review the project descriptions and adjust any wording to accurately reflect your role on each project.
